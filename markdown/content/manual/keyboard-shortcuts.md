# Atalhos de Teclado / Keyboard Shortcuts

Quick reference for keyboard shortcuts across Atlantis apps.

---

## Shell (global / sempre disponível)

| Shortcut | Action |
|---|---|
| `Cmd+K` / `Ctrl+K` | Open the command palette — search apps, actions, and sessions |
| `Esc` | Close the command palette, modal, or dropdown |

---

## Command Palette (`Cmd+K`)

The command palette is the fastest way to navigate Atlantis. It searches:
- App names and descriptions (e.g. type "movies" → Movies & Series)
- Recent apps (shown at the top without typing)
- AI "Ask" sessions (search by session title)

Tabs in the palette:
- **All** — apps + actions + sessions
- **Go to** — apps only
- **Actions** — shell actions (open settings, toggle locale…)
- **Ask** — recent AI conversation sessions
- **Recent** — recently visited apps

## School games (`#/school`)

School games use on-screen controls. On desktop, most games support:

| Key | Action |
|---|---|
| Arrow keys | Move / navigate |
| `Space` / `Enter` | Select / confirm |
| `Backspace` | Delete / go back in word games |

---

## Games — Touch controls (iPad/Mobile)

All games in the Game Room support **on-screen touch controls** on iPad and mobile:
- **Left thumb zone:** Dynamic joystick (appears where your thumb lands)
- **Right side buttons:** Action buttons (jump, attack, bomb…)

Controls auto-hide on desktop (hover+pointer devices) — no overlay on mouse users.

---

## Tip / Dica

Most input fields in Atlantis follow standard browser shortcuts (`Cmd+A`, `Cmd+C`, `Cmd+V`, `Cmd+Z`). If an app-specific shortcut is missing from this list, check the app's help icon or tooltip in the toolbar.
