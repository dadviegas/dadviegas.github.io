# Guia de Pronúncia do Inglês

## Introdução

A pronúncia do inglês pode ser complicada — às vezes as letras não se leem como esperamos! Este guia vai ajudar-te a perceber os sons mais difíceis do inglês e a evitar os erros mais comuns.

---

## Os Sons das Vogais

Em inglês, cada vogal pode ter vários sons diferentes. Veja a diferença!

### A letra "A"

| Som | Como soa | Exemplos |
|-----|----------|---------|
| /æ/ | "é" curto e aberto | **cat**, **bad**, **hat** |
| /eɪ/ | "ei" | **name**, **cake**, **day** |
| /ɑː/ | "a" longo | **car**, **far**, **star** |

### A letra "E"

| Som | Como soa | Exemplos |
|-----|----------|---------|
| /e/ | "é" curto | **bed**, **red**, **best** |
| /iː/ | "i" longo | **these**, **complete** |
| silencioso | não se lê | **name**, **cake** |

### A letra "I"

| Som | Como soa | Exemplos |
|-----|----------|---------|
| /ɪ/ | "i" curto | **sit**, **bit**, **fish** |
| /aɪ/ | "ai" | **like**, **time**, **fine** |

### A letra "O"

| Som | Como soa | Exemplos |
|-----|----------|---------|
| /ɒ/ | "ó" curto | **hot**, **dog**, **stop** |
| /əʊ/ | "ou" | **go**, **home**, **phone** |
| /uː/ | "u" longo | **do**, **to**, **who** |

### A letra "U"

| Som | Como soa | Exemplos |
|-----|----------|---------|
| /ʌ/ | "â" aberto | **cup**, **fun**, **sun** |
| /juː/ | "iu" | **use**, **cute**, **music** |
| /ʊ/ | "u" curto | **put**, **full**, **book** |

> [!TIP]
> O som **"th"** não existe em português! Para fazer este som, coloca a língua entre os dentes e sopra suavemente. Pratica com: **"the"**, **"this"**, **"think"**, **"that"**.

## Sons Difíceis das Consoantes

### O som "TH"

| Som | Como fazer | Exemplos |
|-----|------------|---------|
| **/ð/** (suave) | língua entre os dentes, voz | **the**, **this**, **that**, **there** |
| **/θ/** (duro) | língua entre os dentes, sem voz | **think**, **three**, **thank**, **birthday** |

### O som "W"

O "W" em inglês não existe em português. Soa como um "u" rápido antes de uma vogal:

- **water** → "uóter"
- **window** → "uíndou"
- **what** → "uót"

### O som "R"

O "R" inglês é muito diferente do português! Não se vibra — é um som suave, como se engolisses o "r":

- **red** — não é o "r" forte português, é mais suave
- **river** — os dois "r" são suaves

### O som "V" vs "B"

Em português, "v" e "b" às vezes soam parecidos. Em inglês, são muito diferentes:

| Letra | Como fazer | Exemplo |
|-------|------------|---------|
| **B** | lábios fechados, abre com voz | **ball**, **book**, **big** |
| **V** | dentes de cima nos lábios de baixo | **very**, **visit**, **voice** |

## Letras Silenciosas (Silent Letters)

Em inglês, muitas letras **não se leem**! Aqui estão as mais comuns:

### Letra "K" silenciosa antes de "N"

| Palavra | Pronúncia | Significado |
|---------|-----------|-------------|
| **know** | "nou" | saber |
| **knee** | "ni" | joelho |
| **knife** | "naif" | faca |
| **knock** | "nok" | bater (à porta) |
| **knight** | "nait" | cavaleiro |

### Letra "W" silenciosa antes de "R"

| Palavra | Pronúncia | Significado |
|---------|-----------|-------------|
| **write** | "rait" | escrever |
| **wrong** | "rong" | errado |
| **wrap** | "rap" | embrulhar |
| **wrist** | "rist" | pulso |

### Letra "B" silenciosa depois de "M"

| Palavra | Pronúncia | Significado |
|---------|-----------|-------------|
| **climb** | "claím" | subir |
| **bomb** | "bom" | bomba |
| **lamb** | "lam" | cordeiro |
| **thumb** | "thum" | polegar |
| **comb** | "coum" | pente |

### Letra "GH" silenciosa

| Palavra | Pronúncia | Significado |
|---------|-----------|-------------|
| **night** | "nait" | noite |
| **light** | "lait" | luz / claro |
| **right** | "rait" | direita / certo |
| **thought** | "thót" | pensamento |
| **daughter** | "dóter" | filha |
| **high** | "hái" | alto |

## Palavras Difíceis de Pronunciar

Estas são palavras que muitos alunos (e até adultos!) têm dificuldade em pronunciar:

|---------|---------------------|-------------|
| **world** | "wérld" | mundo |
| **girl** | "gérl" | rapariga |
| **clothes** | "clóuz" | roupa |
| **comfortable** | "cómftabel" | confortável |
| **vegetable** | "véjtebol" | vegetal |
| **February** | "Fébrueri" | Fevereiro |
| **Wednesday** | "Uénzdei" | Quarta-feira |
| **island** | "áiland" | ilha |
| **Wednesday** | "Uénzdei" | Quarta-feira |
| **choir** | "cuáier" | coro |
| **necessary** | "néseseri" | necessário |
| **beautiful** | "biútiful" | bonito/a |

> **"Wednesday"** é uma das palavras mais mal pronunciadas! Soa "Uénzdei" — o "d" do meio não se lê. Podes dividir assim para memorizar: Wed-nes-day.

## Regras de Pronúncia Úteis

### Regra do "E Final"

Quando uma palavra termina em **"e" mudo**, a vogal anterior fica longa:

| Sem "e" final | Com "e" final | Diferença |
|---------------|---------------|-----------|
| **pin** (alfinete) | **pine** (pinho) | /ɪ/ → /aɪ/ |
| **bit** (bocado) | **bite** (morder) | /ɪ/ → /aɪ/ |
| **hop** (saltar num pé) | **hope** (esperança) | /ɒ/ → /əʊ/ |
| **cut** (cortar) | **cute** (giro) | /ʌ/ → /juː/ |

### Palavras Acentuadas (Word Stress)

Em inglês, cada palavra tem uma sílaba mais forte:

| Palavra | Sílaba forte | Pronúncia |
|---------|-------------|-----------|
| **happy** | HAP-py | HÁ-pi |
| **computer** | com-PU-ter | com-PIÚ-ter |
| **important** | im-POR-tant | im-POR-tent |
| **beautiful** | BEA-u-ti-ful | BIÚ-ti-ful |
| **elephant** | EL-e-phant | ÉL-e-fent |
