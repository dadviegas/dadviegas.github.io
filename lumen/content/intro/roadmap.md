# Learning Roadmap

A 4-week plan to go from "I use Claude for autocomplete" to "I ship features I couldn't have shipped alone."

## Week 1 — Foundations & first session

**Goal:** stop being surprised by the model. Run your first real Claude Code session.

- Read **LLM Foundations** end to end (4 short pages).
- Install Claude Code. Run `Your First Session`.
- Write a 30-line `CLAUDE.md` for one of your repos.
- Try 5 different prompts on the same task. Notice which work.

**Drill:** open a real bug in your project. Solve it with Claude Code. Write down what worked and what didn't.

## Week 2 — Prompting & skills

**Goal:** stop writing vague prompts. Install your first skills.

- Read **Prompt Engineering** (101 → Anti-Patterns).
- Do **Drills → Prompting**.
- Read **Skills → What is a Skill?**, then **Skills → Must-Know**.
- Install 2 skills today. Use them tomorrow.

**Drill:** rewrite three prompts you've used this week. Each rewrite should be shorter, more specific, and produce a better answer.

## Week 3 — API & tool use

**Goal:** call Claude from code. Build something tool-using.

- Read **Claude API → Quickstart** through **Tool Use**.
- Build a 50-line script that takes free-text input → calls Claude with one tool → returns structured JSON.
- Add **prompt caching** to it. Watch your cache hit rate.

**Drill:** wire a small Claude call into an existing project of yours. Replace one piece of hand-written logic with an LLM call where it makes sense.

## Week 4 — Agents & ship

**Goal:** loop tools, ship a real artifact.

- Read **Building Agents** + **Drills → Agents**.
- Pick one Capstone from `Drills → Capstones`. Ship it.
- Write a skill that captures something you do every week.

**Drill:** measure. Time three tasks before AI and after. Note where the savings actually are — they're rarely where you expect.

## After week 4

You should now (a) reach for Claude Code first, (b) write tighter prompts than 90% of your peers, (c) ship features faster, (d) know the difference between "delegate to LLM" and "do it yourself."

Then teach someone else. Best test of mastery.
