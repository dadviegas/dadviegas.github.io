# Cores em Inglês 🎨

## Introdução

O mundo é cheio de cores! Vamos aprender os nomes das cores em inglês. Depois de aprenderes, vais conseguir descrever tudo à tua volta em inglês — o teu lápis, a tua mochila, o teu animal de estimação!

---

## As Cores

| Cor | Inglês | Português |
|-----|--------|-----------|
| 🔴 | **red** | vermelho |
| 🔵 | **blue** | azul |
| 🟢 | **green** | verde |
| 🟡 | **yellow** | amarelo |
| 🟠 | **orange** | laranja |
| 🟣 | **purple** | roxo / violeta |
| 🩷 | **pink** | cor-de-rosa |
| ⚫ | **black** | preto |
| ⚪ | **white** | branco |
| 🟤 | **brown** | castanho |

> [!TIP]
> Em inglês, as cores normalmente vêm **antes** do nome do objeto. Por exemplo: **red apple** (maçã vermelha), **blue sky** (céu azul).

Aprende a usar as cores em frases simples:

| Inglês | Português |

| The sky is **blue**. | O céu é **azul**. |

| The sun is **yellow**. | O sol é **amarelo**. |

| The flower is **purple**. | A flor é **roxa**. |
| The pig is **pink**. | O porco é **cor-de-rosa**. |
| The night is **black**. | A noite é **preta**. |
| The snow is **white**. | A neve é **branca**. |
| The chocolate is **brown**. | O chocolate é **castanho**. |

## Perguntar sobre Cores

Em inglês, perguntamos a cor assim:

**Pergunta:** What color is it? — Que cor é?

**Respostas:**
- **It's red!** — É vermelho!
- **It's blue!** — É azul!
- **It's green!** — É verde!

---

## Cores Mistas — Curiosidades!

> [!TIP]
> Sabias que podes misturar cores para criar novas cores?
> - **Red + Yellow = Orange** (Vermelho + Amarelo = Laranja)
> - **Blue + Yellow = Green** (Azul + Amarelo = Verde)
> - **Red + Blue = Purple** (Vermelho + Azul = Roxo)
> - **Red + White = Pink** (Vermelho + Branco = Rosa)

### Exercício 2 — Completa as frases

Usa a cor correta em inglês:

1. The sky is ________. (azul)
2. The apple is ________. (vermelho)
3. The grass is ________. (verde)
4. The sun is ________. (amarelo)
5. The night is ________. (preto)

### Exercício 3 — Pinta e escreve

Imagina que tens lápis de cor à tua frente. Para cada lápis, escreve a frase em inglês:

1. (lápis vermelho) → This pencil is ________.
2. (lápis azul) → This pencil is ________.
3. (lápis verde) → This pencil is ________.
4. (lápis amarelo) → This pencil is ________.

### Exercício 4 — A minha cor preferida

Responde em inglês:

**What is your favorite color?** (Qual é a tua cor preferida?)

**My favorite color is ________!**
