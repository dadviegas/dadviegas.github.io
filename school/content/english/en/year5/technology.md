# Technology Vocabulary

## Introduction

Technology is one of the fastest-evolving areas of the English language. New words appear every year as new inventions emerge. This lesson covers both established tech vocabulary and the latest digital concepts.

## Tech Verbs

| Verb | Portuguese | Example |
|------|-----------|---------|
| **to code / programme** | programar | She **codes** in Python. |
| **to hack** | hackear / piratear | The site was **hacked**. |
| **to encrypt** | encriptar | Data should be **encrypted**. |
| **to automate** | automatizar | Factories **automate** production. |
| **to process** | processar | Computers **process** data quickly. |
| **to store** | armazenar | Files are **stored** in the cloud. |
| **to connect** | ligar / conectar | **Connect** to the Wi-Fi. |
| **to update** | atualizar | Please **update** your phone. |
| **to charge** | carregar | I need to **charge** my laptop. |

## Talking About Technology

| Expression | Portuguese |
|------------|-----------|
| **Technology has changed our lives.** | A tecnologia mudou as nossas vidas. |
| **Artificial intelligence is developing rapidly.** | A IA está a desenvolver-se rapidamente. |
| **Robots may replace some jobs.** | Os robôs podem substituir alguns empregos. |
| **Privacy is a major concern.** | A privacidade é uma preocupação importante. |
| **We rely too much on technology.** | Dependemos demasiado da tecnologia. |

## Exercises

### Exercise 1 — Match the definition

| Term | | Definition |
|------|-|-----------|
| algorithm | | a mistake in code |
| bug | | a step-by-step set of instructions |
| cloud | | stores data over the internet |
| VPN | | protects your privacy online |

### Exercise 2 — Fill in the gap

1. AI stands for ________ ________.
2. Files are ________ in the cloud.
3. A ________ can fly without a pilot.
4. Smart devices that connect to the internet are called the ________ of ________.

### Exercise 3 — Pros and cons

Write 4 sentences about the advantages and disadvantages of artificial intelligence.

### Exercise 4 — Technology essay

Write a paragraph (100 words) on one of these topics:

- **"Will robots take over our jobs in the future?"**
- **"Is technology making us smarter or lazier?"**

Include your opinion, at least one argument for and against, and a conclusion.

> [!TIP]
> Technology vocabulary often comes directly from English into other languages (hardware, software, Wi-Fi, blockchain). This means if you know the English term, you probably already understand it in Portuguese too!
