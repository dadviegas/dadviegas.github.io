# Addition with Carrying

When the ones digits add up to **10 or more**, we **carry** to the tens column.

---

## How carrying works

### Example: $47 + 35$

**Step 1** — Add the ones:

$$7 + 5 = 12$$

12 has 1 ten and 2 ones. Write the **2** in the ones column and **carry 1** to the tens.

**Step 2** — Add the tens (including the carry):

$$4 + 3 + 1_{\text{carry}} = 8$$

**Result:**

```
 (1)
  47
+ 35
----
  82
```

$$47 + 35 = 82$$

---

## Another example: $68 + 24$

```
 (1)
  68
+ 24
----
  92
```

- Ones: $8 + 4 = 12$ → write **2**, carry **1**
- Tens: $6 + 2 + 1 = 9$ → write **9**

$$68 + 24 = 92$$

---

## Double carry: $76 + 58$

```
(1)(1)
   76
+  58
-----
  134
```

- Ones: $6 + 8 = 14$ → write **4**, carry **1**
- Tens: $7 + 5 + 1 = 13$ → write **3**, carry **1** to hundreds

$$76 + 58 = 134$$

> [!IMPORTANT]
> The carry is like "passing the extra to the next column." This is the foundation of all large-number addition!
