# Leitura e Escrita — 1.º Ano

## O Alfabeto

O alfabeto português tem **26 letras**. Cada letra tem um nome e um som.

| Letra | Nome | Letra | Nome |
|-------|------|-------|------|
| A a | á | N n | ene |
| B b | bê | O o | ó |
| C c | cê | P p | pê |
| D d | dê | Q q | quê |
| E e | é | R r | erre |
| F f | efe | S s | esse |
| G g | gê | T t | tê |
| H h | agá | U u | u |
| I i | i | V v | vê |
| J j | jota | W w | dáblio |
| L l | ele | X x | xis |
| M m | eme | Y y | ípsilon |
| K k | capa | Z z | zê |

> [!TIP]
> Canta o alfabeto! Aprender a ordem das letras ajuda a usar o dicionário.

---

## Vogais e Consoantes

As letras dividem-se em **vogais** e **consoantes**.

**Vogais:** A, E, I, O, U

**Consoantes:** todas as outras letras (B, C, D, F, G, H, J, L, M, N, P, Q, R, S, T, V, X, Z…)

> [!NOTE]
> As vogais são o "coração" das sílabas. Cada sílaba tem sempre pelo menos uma vogal.

---

## As Sílabas

Uma **sílaba** é um grupo de sons que se diz de uma só vez.

| Palavra | Sílabas | N.º de sílabas |
|---------|---------|----------------|
| ca-sa | ca / sa | 2 |
| bo-la | bo / la | 2 |
| á-r-vo-re | á / rvo / re | 3 |
| pá | pá | 1 |

> [!TIP]
> Bate palmas para contar as sílabas! Cada palmada = uma sílaba.

---

## Leitura de Palavras Simples

Junta as letras para formar palavras:

- **b + a = ba** → **bata**
- **m + e = me** → **mesa**
- **p + i = pi** → **pipa**
- **s + o = so** → **solo**
- **t + u = tu** → **tubo**

---

## Escrever o Meu Nome

O meu nome começa com letra **maiúscula**.

> [!IMPORTANT]
> Os nomes próprios (de pessoas, de cidades, de países) escrevem-se sempre com letra maiúscula.

Exemplos: **Ana**, **Tomás**, **Lisboa**, **Portugal**

## Experimenta! 🎯

1. **Ordena as letras** do alfabeto e sublinha todas as vogais: E, B, A, O, D, I, U.
2. **Bate palmas** e conta as sílabas: *borboleta*, *sol*, *janela*, *pé*.
3. **Escreve o teu nome** em letra maiúscula e divide-o em sílabas.
4. **Liga as letras** para formar uma palavra: p + a + t + o = \_\_\_\_\_
