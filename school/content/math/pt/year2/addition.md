# Adição com Transporte

Quando a soma das unidades é **maior ou igual a 10**, fazemos um **transporte** para as dezenas.

---

## Como funciona o transporte

### Exemplo: $47 + 35$

**Passo 1** — Somamos as unidades:

$$7 + 5 = 12$$

12 tem 1 dezena e 2 unidades. Escrevemos o **2** nas unidades e **transportamos 1** para as dezenas.

**Passo 2** — Somamos as dezenas (incluindo o transporte):

$$4 + 3 + 1_{\text{transporte}} = 8$$

**Resultado:**

```
 (1)
  47
+ 35
----
  82
```

$$47 + 35 = 82$$

---

## Outro exemplo: $68 + 24$

```
 (1)
  68
+ 24
----
  92
```

- Unidades: $8 + 4 = 12$ → escreve **2**, transporta **1**
- Dezenas: $6 + 2 + 1 = 9$ → escreve **9**

$$68 + 24 = 92$$

---

## Exemplo com duas ordens de transporte: $76 + 58$

```
(1)(1)
   76
+  58
-----
  134
```

- Unidades: $6 + 8 = 14$ → escreve **4**, transporta **1**
- Dezenas: $7 + 5 + 1 = 13$ → escreve **3** nas dezenas, transporta **1** para as centenas

$$76 + 58 = 134$$

> [!IMPORTANT]
> O transporte é como "pedir emprestado à ordem seguinte". É a base de toda a adição com números maiores!
