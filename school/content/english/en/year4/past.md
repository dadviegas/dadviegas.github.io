# The Simple Past Tense

## Introduction

We use the **simple past** to talk about actions or events that happened and finished in the past. It is one of the most important tenses in English!

---

## Regular Verbs — Past Tense Formation

Add **-ed** to the base verb:

| Base verb | Past tense | Portuguese |
|-----------|-----------|-----------|
| **walk** | walk**ed** | andou / andei |
| **talk** | talk**ed** | falou / falei |
| **play** | play**ed** | jogou / joguei |
| **watch** | watch**ed** | viu / vi |
| **listen** | listen**ed** | ouviu / ouvi |
| **work** | work**ed** | trabalhou / trabalhei |
| **finish** | finish**ed** | acabou / acabei |
| **visit** | visit**ed** | visitou / visitei |

### Spelling rules for -ed

| Rule | Example |
|------|---------|
| Most verbs → add **-ed** | play → play**ed** |
| Verb ends in **-e** → add **-d** | like → like**d** |
| Verb ends in consonant-vowel-consonant → double last letter | stop → stop**p**ed |
| Verb ends in **-y** after consonant → **-ied** | study → stud**ied** |

## Irregular Verbs — Past Tense

Many common verbs have irregular past forms that must be memorized:

| Base | Past | Portuguese |
|------|------|-----------|
| **be** | was / were | ser / estar |
| **have** | had | ter / tive |
| **go** | went | ir / fui |
| **come** | came | vir / vim |
| **see** | saw | ver / vi |
| **eat** | ate | comer / comi |
| **drink** | drank | beber / bebi |
| **do** | did | fazer / fiz |
| **say** | said | dizer / disse |
| **get** | got | obter / obtive |
| **make** | made | fazer / fiz |
| **take** | took | pegar / peguei |
| **give** | gave | dar / dei |
| **find** | found | encontrar / encontrei |
| **think** | thought | pensar / pensei |
| **know** | knew | saber / soube |
| **write** | wrote | escrever / escrevi |
| **read** | read | ler / li |
| **run** | ran | correr / corri |
| **swim** | swam | nadar / nadei |
| **fly** | flew | voar / voei |
| **buy** | bought | comprar / comprei |
| **bring** | brought | trazer / trouxe |

> [!TIP]
> There is no shortcut for irregular verbs — you need to memorize them. But the good news is that the most common verbs are irregular, so you'll practise them all the time!

## Positive Sentences

Subject + past verb + object/complement

| English | Portuguese |
|---------|-----------|
| I **walked** to school. | Fui a pé para a escola. |
| She **ate** a pizza. | Ela comeu uma pizza. |
| They **played** football. | Eles jogaram futebol. |
| He **was** happy. | Ele estava feliz. |
| We **went** to the beach. | Fomos à praia. |

---

## Negative Sentences

Subject + **didn't** (did not) + base verb

| Positive | Negative |
|----------|---------|
| I walked to school. | I **didn't** walk to school. |
| She ate pizza. | She **didn't** eat pizza. |
| They played football. | They **didn't** play football. |

> [!TIP]
> With **didn't** the main verb goes back to the **base form**: *She didn't **eat*** (not *didn't ate*).

---

## Questions

**Did** + subject + base verb + ?

| Question | Short answer |
|----------|-------------|
| **Did** you walk to school? | Yes, I **did**. / No, I **didn't**. |
| **Did** she eat pizza? | Yes, she **did**. / No, she **didn't**. |
| **What did** you eat? | I ate pasta. |
| **Where did** they go? | They went to the park. |
| **When did** he arrive? | He arrived at three. |

| Expression | Portuguese |
|------------|-----------|

| **last week** | na semana passada |

| **ago** | há (tempo) |
| **two days ago** | há dois dias |
