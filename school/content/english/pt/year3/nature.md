# A Natureza em Inglês

## Introdução

A natureza é linda! Em inglês dizemos **nature**. Há árvores, flores, rios, montanhas e muito mais. Vamos aprender as palavras da natureza em inglês!

---

## Elementos da Natureza — *Elements of Nature*

### Plantas e Paisagens — *Plants and Landscapes*

| Inglês | Português |
|--------|-----------|
| **tree** | árvore |
| **flower** | flor |
| **grass** | erva / relva |
| **leaf** (plural: **leaves**) | folha (folhas) |
| **forest** | floresta |
| **river** | rio |
| **mountain** | montanha |
| **sea** | mar |
| **lake** | lago |
| **beach** | praia |
| **field** | campo |
| **hill** | colina |

### O Céu e o Tempo — *The Sky and Weather*

| Inglês | Português |
|--------|-----------|
| **sun** | sol |
| **moon** | lua |
| **star** | estrela |
| **cloud** | nuvem |
| **rain** | chuva |
| **wind** | vento |
| **snow** | neve |
| **rainbow** | arco-íris |
| **sky** | céu |

> [!TIP]
> Em inglês, **leaf** (folha) tem um plural irregular: **leaves**! É como **wolf** → **wolves** (lobo → lobos).

## Frases sobre a Natureza

Aprende a descrever a natureza em inglês:

| Inglês | Português |
|--------|-----------|
| **The sun is shining.** | O sol está a brilhar. |
| **The wind is blowing.** | O vento está a soprar. |
| **It is raining.** | Está a chover. |
| **The flowers are beautiful.** | As flores são bonitas. |
| **The river is long.** | O rio é comprido. |
| **The mountain is very high.** | A montanha é muito alta. |
| **I love the sea!** | Adoro o mar! |
| **The moon is bright tonight.** | A lua está brilhante esta noite. |
| **I can see the stars.** | Consigo ver as estrelas. |
| **The forest is big and green.** | A floresta é grande e verde. |

## Cores na Natureza — *Colours in Nature*

| Elemento | Cor em Inglês | Cor em Português |
|----------|--------------|-----------------|
| Tree | green | verde |
| Flower | red, yellow, pink | vermelho, amarelo, cor-de-rosa |
| Sky | blue | azul |
| Sun | yellow | amarelo |
| Cloud | white | branco |
| Sea | blue / green | azul / verde |
| Mountain | grey / brown | cinzento / castanho |
| Rainbow | all colours! | todas as cores! |

> [!TIP]
> Podes combinar palavras! Por exemplo: **a green tree** (uma árvore verde), **a blue river** (um rio azul), **a yellow flower** (uma flor amarela). O adjetivo vem ANTES do nome em inglês!

## Um Poema da Natureza

Lê este pequeno poema em inglês:

> *I see a tree, so tall and green,*
> *A river blue, a flower between.*
> *The sun is bright, the sky is clear,*
> *The birds are singing — summer's here!*

**Tradução:**
> Vejo uma árvore, tão alta e verde,
> Um rio azul, uma flor entre elas.
> O sol é brilhante, o céu está limpo,
> Os pássaros cantam — o verão chegou!
