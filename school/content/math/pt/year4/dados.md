# Tratamento de Dados

Vamos aprender a **recolher**, **organizar** e **interpretar** dados!

---

## Recolher Dados

Para estudar um tema, precisamos de recolher **dados** (informações).

**Exemplo:** Qual é a fruta favorita da turma?

Perguntamos a cada colega e anotamos as respostas.

---

## Tabelas de Frequência

Organizamos os dados numa **tabela de frequência**:

| Fruta | Contagem | Frequência |
|---|---|---|
| 🍎 Maçã | ꕥꕥꕥꕥ | 4 |
| 🍌 Banana | ꕥꕥꕥꕥꕥꕥ | 6 |
| 🍊 Laranja | ꕥꕥꕥ | 3 |
| 🍓 Morango | ꕥꕥꕥꕥꕥꕥꕥ | 7 |
| 🍇 Uvas | ꕥꕥ | 2 |

**Total** = 4 + 6 + 3 + 7 + 2 = **22 alunos**

> [!TIP]
> Usa **marcas de contagem** (tracinhos de 5 em 5) para não te perderes: ꕥꕥꕥꕥ = 4

---

## Gráfico de Barras

O gráfico de barras usa **barras** para mostrar os dados visualmente.

Aqui está o gráfico da fruta favorita da turma:

```chart
type: bar
title: Fruta Favorita da Turma
labels: [Maçã, Banana, Laranja, Morango, Uvas]
data: [4, 6, 3, 7, 2]
colors: [#ff6b6b, #ffd93d, #ff9f43, #ee5a24, #6c5ce7]
```

**Regras:**
1. O eixo horizontal tem as **categorias** (frutas)
2. O eixo vertical tem a **frequência** (números)
3. As barras têm todas a **mesma largura**
4. A altura corresponde ao **valor**

> [!NOTE]
> Quanto mais **alta** a barra, mais pessoas escolheram essa opção!

---

## Gráfico Circular (Queijo)

O gráfico circular mostra as partes de um todo — como fatias de uma pizza!

```chart
type: pie
title: Fruta Favorita (%)
labels: [Maçã, Banana, Laranja, Morango, Uvas]
data: [4, 6, 3, 7, 2]
colors: [#ff6b6b, #ffd93d, #ff9f43, #ee5a24, #6c5ce7]
```

---

## Pictograma

Um **pictograma** usa **imagens** em vez de barras.

Cada imagem vale um certo número:

| Fruta | Representação (cada 🍎 = 2 alunos) |
|---|---|
| Maçã | 🍎🍎 (= 4) |
| Banana | 🍎🍎🍎 (= 6) |
| Morango | 🍎🍎🍎½ (= 7) |

> [!IMPORTANT]
> Verifica sempre a **legenda** do pictograma para saberes quanto vale cada imagem!

---

## Gráfico de Linhas

O gráfico de linhas mostra como os dados **mudam ao longo do tempo**:

```chart
type: line
title: Temperatura durante a semana (°C)
labels: [Seg, Ter, Qua, Qui, Sex, Sáb, Dom]
data: [18, 20, 22, 19, 23, 25, 24]
```

> [!TIP]
> O gráfico de linhas é ideal para mostrar **tendências** — a linha sobe quando o valor aumenta e desce quando diminui!

---

## A Moda

A **moda** é o valor que aparece **mais vezes** num conjunto de dados.

No nosso exemplo: 🍓 Morango (7 votos) é a **moda**.

**Outro exemplo:** notas de um teste: 7, 8, 8, 9, 8, 10, 7

A moda é **8** (aparece 3 vezes).

---

## Interpretar Gráficos

Quando lês um gráfico, pergunta:
- Qual tem o valor **mais alto**? (moda)
- Qual tem o valor **mais baixo**?
- Qual é a **diferença** entre o maior e o menor?
- Qual é o **total**?

---

## Experimenta!

1. **Pesquisa** — pergunta a 15 colegas qual é a cor favorita. Faz uma tabela de frequência.
2. **Gráfico** — com os dados, desenha um gráfico de barras.
3. **Moda** — qual é a cor mais escolhida? Essa é a moda!
4. **Pictograma** — redesenha os dados usando emojis (cada emoji = 2 pessoas).
