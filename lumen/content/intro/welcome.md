# Welcome to Lumen

Lumen is a hands-on study guide for becoming an **AI-native engineer** — someone who ships better software, faster, by working *with* Claude (and LLMs in general) rather than around them.

## Who this is for

You already know how to code. You can ship a frontend, debug a backend, navigate a monorepo. What you want is to **stop using AI as autocomplete** and start using it as a senior collaborator: a pair-programmer that drafts, refactors, reviews, audits, and automates.

## What you'll learn

The site is organised as a ladder. You can read top-to-bottom, or jump to any rung:

1. **LLM Foundations** — how the model actually works (tokens, context, sampling). Just enough theory to stop being surprised.
2. **Claude Code (CLI)** — the day-to-day driver. Sessions, `CLAUDE.md`, slash commands, hooks, MCP, subagents.
3. **Skills** — the killer feature most people miss. What a skill is, how to write one, which ones to install today.
4. **Prompt Engineering** — clarity, roles, few-shot, chain-of-thought, XML structuring, evals.
5. **Claude API** — the messages API, tool use, streaming, prompt caching, extended thinking, vision.
6. **Building Agents** — the Agent SDK, tool loops, patterns, sandboxing.
7. **Frontend with Claude** — workflow, components, design systems, debugging, refactor playbook, tests as a spec.
8. **Drills (Grill Me)** — exercises you do *in* Claude Code to lock the skill in.
9. **Resources** — official docs, cheat sheet, glossary.

## How to use this site

- **Beginners:** read `Start Here` → `LLM Foundations` → `Claude Code (CLI)` in order. Skip nothing.
- **Intermediate:** start at `Claude Code` and `Skills`. Skim foundations.
- **Advanced:** jump to `Prompt Engineering → Evals`, then `Agents`, then the `Drills`.

Every page ends with a **Practice** block — a small task you do *now*, in your own terminal, before moving on. Reading without practising is theatre.
