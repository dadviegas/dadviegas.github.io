# The Classroom

## Introduction

The classroom is where we learn! Knowing the names of classroom objects and understanding your teacher's instructions in English will help you every single day.

---

> When you pick up an object in class, try to say its name in English quietly to yourself. Repetition is the key to remembering!

## Classroom Instructions

These are the phrases your teacher might say:

| Instruction | Portuguese |
|-------------|-----------|
| **Sit down, please.** | Sentem-se, por favor. |
| **Stand up, please.** | Levantem-se, por favor. |
| **Open your book.** | Abram o livro. |
| **Close your book.** | Fechem o livro. |
| **Listen carefully.** | Ouçam com atenção. |
| **Repeat after me.** | Repitam depois de mim. |
| **Write in your notebook.** | Escrevam no caderno. |
| **Look at the board.** | Olhem para o quadro. |
| **Work in pairs.** | Trabalhem aos pares. |
| **Be quiet, please.** | Façam silêncio, por favor. |
| **Well done!** | Muito bem! |

## Useful Classroom Phrases (for students)

| Phrase | Portuguese |
|--------|-----------|
| **Can I go to the toilet?** | Posso ir à casa de banho? |
| **I don't understand.** | Não percebo. |
| **Can you repeat that?** | Pode repetir? |
| **How do you say … in English?** | Como se diz … em inglês? |
| **Can I borrow a pencil?** | Posso pedir um lápis emprestado? |
| **I have a question.** | Tenho uma pergunta. |

> [!TIP]
> Don't be afraid to say **"I don't understand"** or **"Can you repeat that?"** — asking for help is smart!

## Where Is It? — Prepositions

Learn to say where things are:

| Preposition | Example |
|-------------|---------|
| **on** | The book is **on** the desk. |
| **in** | The pencil is **in** the pencil case. |
| **under** | The bag is **under** the chair. |
| **next to** | The door is **next to** the window. |

## Exercises

### Exercise 1 — Name the object

What is it in English?

1. You write with it (not a pen) → ________
2. You carry your books in it → ________
3. The teacher writes on it → ________
4. You erase mistakes with it → ________
5. You measure lines with it → ________

### Exercise 2 — Instruction match

Match the instruction to what you do:

| Instruction | | Action |
|-------------|-|--------|
| Open your book | | Stop talking |
| Sit down | | Get your pen ready |
| Be quiet | | Go to your seat |
| Write in your notebook | | Turn to page 1 |

### Exercise 3 — Where is it?

Write a sentence using **on**, **in**, **under**, or **next to**:

1. The ruler / desk → ________
2. The eraser / pencil case → ________
3. The bag / chair → ________
