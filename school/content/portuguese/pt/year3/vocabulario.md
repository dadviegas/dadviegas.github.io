# Vocabulário — 3.º Ano

## Sinónimos

**Sinónimos** são palavras com o mesmo significado ou significado muito próximo.

| Palavra | Sinónimos |
|---------|----------|
| bonito | lindo, formoso, belo, atraente |
| triste | melancólico, abatido, pesaroso |
| começar | iniciar, arrancar, encetar |
| falar | dizer, discursar, proferir |
| ajudar | auxiliar, apoiar, socorrer |

> [!TIP]
> Usar sinónimos enriquece o vocabulário e evita a repetição. Mas atenção: nem sempre dois sinónimos são completamente intercambiáveis!

---

## Antónimos

**Antónimos** são palavras com significado oposto.

| Palavra | Antónimo | Formação |
|---------|---------|---------|
| feliz | infeliz | prefixo in- |
| possível | impossível | prefixo im- |
| ordenado | desordenado | prefixo des- |
| honesto | desonesto | prefixo des- |
| capaz | incapaz | prefixo in- |

> [!NOTE]
> Os prefixos **in-**, **im-**, **des-**, **i-** e **ir-** são os mais usados para formar antónimos.

---

## Homófonos

**Homófonos** são palavras que se pronunciam igual mas têm significados diferentes (e muitas vezes escrevem-se de forma diferente).

| Par de homófonos | Significados |
|------------------|-------------|
| *cozer* / *coser* | cozinhar / costurar |
| *sela* / *cela* | assento da sela / cela da prisão |
| *acento* / *assento* | sinal gráfico / lugar onde se senta |
| *conserto* / *concerto* | reparação / espetáculo musical |
| *seção* / *sessão* | divisão / período de tempo |

> [!IMPORTANT]
> Para saber qual a grafia correta, usa o contexto da frase!

---

## Família de Palavras

Palavras da mesma família partilham a mesma **raiz** (ou radical).

| Raiz | Família |
|------|---------|
| **livr-** | livro, livraria, livreiro, livrete, livrar |
| **mar-** | mar, marinha, marinheiro, marítimo, maré |
| **luz** | luz, luminoso, iluminar, lustre, luzir |
| **campo** | campo, campina, campestre, acampar, acampamento |

---

## Campo Semântico

O **campo semântico** refere-se aos diferentes significados que uma mesma palavra pode ter.

**Exemplo: a palavra *banco***

| Frase | Significado de *banco* |
|-------|----------------------|
| Sentei-me no *banco* do jardim. | assento |
| Fui ao *banco* levantar dinheiro. | instituição financeira |
| O *banco* de areia bloqueou o rio. | acumulação de areia |

> [!TIP]
> Uma palavra pode ter vários significados — isso chama-se **polissemia**. O dicionário lista todas as aceções!

## Experimenta!

1. **Substitui a palavra repetida** por um sinónimo: *O menino é muito feliz. O menino ri sempre. O menino brinca com todos.*
2. **Forma o antónimo** com prefixo: *real* → \_\_\_\_ / *legal* → \_\_\_\_ / *apareceu* → \_\_\_\_.
3. **Escolhe o homófono correto**: *Ela foi \_\_\_\_ (coser/cozer) o jantar.* / *Preciso de \_\_\_\_ (coser/cozer) o botão.*
4. **Cria a família de palavras** a partir de *peixe* — encontra pelo menos 4 palavras.
