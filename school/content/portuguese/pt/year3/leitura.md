# Leitura e Escrita — 3.º Ano

## Estratégias de Leitura

Bons leitores usam estratégias antes, durante e depois de ler.

| Quando | Estratégia |
|--------|-----------|
| **Antes** | Olha para o título e imagens; antecipa o tema |
| **Antes** | Ativa o que já sabes sobre o assunto |
| **Durante** | Sublinha as ideias mais importantes |
| **Durante** | Descobre o significado de palavras desconhecidas pelo contexto |
| **Depois** | Faz um resumo com as tuas palavras |
| **Depois** | Dá a tua opinião sobre o texto |

> [!TIP]
> Se encontrares uma palavra que não conheces, lê a frase toda — muitas vezes o contexto ajuda a perceber o significado!

---

## Como Fazer um Resumo

Um **resumo** conta as ideias principais de um texto de forma breve.

**Passos para resumir:**
1. Lê o texto com atenção.
2. Identifica as personagens principais e o tema.
3. Seleciona as ideias mais importantes (início, meio, fim).
4. Escreve o resumo com as tuas palavras, sem copiar frases inteiras.

> [!IMPORTANT]
> Um resumo **não inclui** todos os detalhes — só o essencial! Deve ser muito mais curto do que o texto original.

---

## Tipos de Leitura

| Tipo | Como se faz | Para quê |
|------|------------|---------|
| Leitura silenciosa | Lês apenas com os olhos | Compreensão pessoal |
| Leitura em voz alta | Lês claramente para os outros ouvirem | Partilhar o texto |
| Leitura expressiva | Lês com entoação e emoção | Teatro, poesia |

---

## Escrever Textos Variados

Este ano aprendes a escrever diferentes tipos de texto:

- **Texto narrativo** — conta uma história
- **Texto descritivo** — descreve uma pessoa, animal, lugar ou objeto
- **Texto instrucional** — explica como fazer algo
- **Texto poético** — usa linguagem criativa com ritmo e rima

> [!NOTE]
> Antes de escrever, planeia o teu texto: faz um rascunho com as ideias, escreve o texto e depois revê-o.

---

## Revisão da Escrita

Quando terminares de escrever, verifica:

- [ ] As frases começam com maiúscula e têm ponto final?
- [ ] As palavras estão escritas corretamente?
- [ ] O texto tem início, meio e fim?
- [ ] As ideias estão organizadas e fazem sentido?

## Experimenta! 🎯

1. **Lê um texto curto** e sublinha: a vermelho as personagens, a azul o lugar, a verde o acontecimento principal.
2. **Faz o resumo** de uma história que conheces em 3 frases (início, meio, fim).
3. **Escreve um parágrafo** descrevendo a tua sala de aula (usa pelo menos 3 adjetivos).
4. **Usa estas estratégias**: antes de ler este ficheiro, o que esperavas encontrar? Depois de ler, o que aprendeste de novo?
