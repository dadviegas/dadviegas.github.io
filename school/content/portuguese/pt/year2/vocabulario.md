# Vocabulário — 2.º Ano

## Sinónimos

**Sinónimos** são palavras com significado igual ou parecido.

| Palavra | Sinónimos |
|---------|----------|
| bonito | lindo, belo, formoso |
| contente | feliz, alegre, satisfeito |
| rápido | veloz, ligeiro, ágil |
| falar | dizer, contar, comunicar |
| grande | enorme, imenso, vasto |

> [!TIP]
> Usar sinónimos torna a tua escrita mais interessante — evita repetir sempre a mesma palavra!

---

## Antónimos

**Antónimos** são palavras com significado contrário.

| Palavra | Antónimo |
|---------|---------|
| frio | quente |
| alto | baixo |
| cheio | vazio |
| abrir | fechar |
| dia | noite |
| dentro | fora |

> [!NOTE]
> Muitos antónimos formam-se com prefixos como **in-**, **des-**, **im-**:
> *feliz* → *in**feliz*** / *fazer* → *des**fazer*** / *possível* → *im**possível***

---

## Família de Palavras

Palavras da mesma família partilham a mesma **raiz** e têm significados relacionados.

| Raiz | Família de palavras |
|------|-------------------|
| **peixe** | peixe, peixaria, peixeiro, pescado |
| **leite** | leite, leiteiro, leitaria, lácteo |
| **terra** | terra, terreno, enterrar, terraço |
| **água** | água, aguado, aguaceiro, aguarela |

> [!TIP]
> Identificar a raiz de uma palavra ajuda a perceber o seu significado e a escrever corretamente!

---

## Campo Lexical

O **campo lexical** é o conjunto de palavras relacionadas com um mesmo tema.

**Campo lexical do desporto:**
*bola, campo, equipa, árbitro, golo, jogo, treino, atleta, corrida, nadar*

**Campo lexical da natureza:**
*árvore, flor, rio, montanha, sol, chuva, vento, animal, floresta, nuvem*

> [!NOTE]
> O campo lexical reúne palavras de classes diferentes (nomes, adjetivos, verbos) sobre o mesmo tema.

2. **Escreve o antónimo**: *triste* → \_\_\_\_ / *subir* → \_\_\_\_ / *limpo* → \_\_\_\_.

4. **Agrupa as palavras** pelo campo lexical (escola / praia): *areia, caderno, onda, professora, concha, quadro, mergulhar, lápis*.
