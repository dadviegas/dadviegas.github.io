# The First Conditional

## Introduction

The **first conditional** is used to talk about real, possible situations in the future and their probable consequences. It is one of the most common grammatical structures in English.

---

## Structure

> **If + present simple, will + base verb**

| Part | Tense | Example |
|------|-------|---------|
| Condition (if-clause) | present simple | **If it rains** |
| Result (main clause) | will + base verb | **I will stay at home.** |

**Full sentence:** *If it rains, I will stay at home.*

> [!TIP]
> The **if-clause** can come first or second. When it comes first, use a **comma**. When it comes second, no comma is needed:
> - **If it rains,** I'll stay home. ← comma
> - I'll stay home **if it rains.** ← no comma

---

## More Examples

| If-clause | Result clause |
|-----------|--------------|
| If you study hard, | you will pass the exam. |
| If she misses the bus, | she will be late. |
| If it's sunny tomorrow, | we'll go to the beach. |
| If you don't eat breakfast, | you will feel hungry. |
| If they win the match, | they will celebrate. |
| If I have enough money, | I'll buy a new bike. |

---

## Negative Forms

You can make either part (or both) negative:

| Example | Meaning |
|---------|---------|
| If you **don't** study, you **won't** pass. | Not studying → not passing |
| If she **doesn't** come, I **won't** wait. | She doesn't come → I won't wait |
| If it **isn't** cold, we **won't** need coats. | Not cold → no coats needed |

---

## Questions with the First Conditional

| Question | Answer |
|----------|--------|
| **What will you do if it rains?** | If it rains, I'll watch TV. |
| **Will you come if I invite you?** | Yes, I will / No, I won't. |
| **What will happen if we miss the train?** | We'll have to take a taxi. |

---

## Unless = If not

**Unless** means "if not" and can replace negative conditions:

| With "if not" | With "unless" |
|---------------|---------------|
| If you **don't** hurry, you'll miss the bus. | **Unless** you hurry, you'll miss the bus. |
| If it **doesn't** stop raining, we'll cancel. | **Unless** it stops raining, we'll cancel. |

---

## Common Uses of the First Conditional

| Use | Example |
|-----|---------|
| **Warnings** | If you touch that, you'll burn yourself! |
| **Promises** | If you help me, I'll buy you ice cream. |
| **Offers** | If you need help, I'll explain it. |
| **Threats** | If you're late again, the teacher will call home. |
| **Negotiations** | If you clean your room, you can go out. |

---

## Second Conditional (preview)

The **second conditional** is used for imaginary or unlikely situations:

> **If + past simple, would + base verb**

- *If I **won** the lottery, I **would** travel the world.* (imaginary)
- *If she **were** taller, she **would** be a model.* (unlikely)

This is different from the first conditional, which describes **real possibilities**.

## Exercises

### Exercise 1 — Complete the sentence

Use the correct form of the verb:

1. If it ________ (rain), we ________ (not go) to the park.
2. If she ________ (study), she ________ (pass) the test.
3. If you ________ (be) late, the teacher ________ (not be) happy.
4. I ________ (help) you if you ________ (ask) me.

### Exercise 2 — Match the halves

|----------|-|---------------|

| If it rains, | | you'll feel ill. |
| If I finish early, | | you'll miss the bus. |
| If you don't leave now, | | I'll call you. |

### Exercise 3 — Rewrite with "unless"

1. If you don't hurry, we'll be late. → Unless ________
2. If it doesn't stop raining, the match will be cancelled. → Unless ________

### Exercise 4 — Chains of conditionals

Continue the chain — what happens next?

Start: *If I study hard, I will pass my exams.*
→ *If I pass my exams, I will ________.*
→ *If I ________, I will ________.*
→ Continue for 3–4 steps.

### Exercise 5 — Real situations

Write 6 first conditional sentences about real possibilities in your life. Think about school, weather, sport, or your family.

> [!TIP]
> Don't confuse the first and second conditionals! First = real/possible situation (present tense in if-clause). Second = imaginary/unlikely situation (past tense in if-clause).
