# Gramática — 1.º Ano

## A Frase

Uma **frase** é um conjunto de palavras com sentido.

- Uma frase começa com **letra maiúscula**.
- Uma frase termina com um **sinal de pontuação** (. ! ?).

| Exemplo | Tipo |
|---------|------|
| O gato dorme. | frase afirmativa |
| A Maria corre! | frase exclamativa |
| Tens um lápis? | frase interrogativa |

> [!NOTE]
> Uma palavra sozinha **não é** uma frase. "Casa." pode ser uma frase muito curta, mas tem de ter sentido completo.

---

## O Nome

O **nome** é a palavra que serve para designar pessoas, animais ou coisas.

| Tipo de nome | Exemplos |
|-------------|---------|
| Pessoa | menina, professor, pai |
| Animal | cão, gato, pássaro |
| Coisa | mesa, bola, livro |

> [!TIP]
> Para descobrir se uma palavra é um nome, pergunta: "É uma pessoa, um animal ou uma coisa?" Se sim, é um nome!

---

## Masculino e Feminino

Os nomes têm **género**: masculino ou feminino.

| Masculino | Feminino |
|-----------|----------|
| o menino | a menina |
| o gato | a gata |
| o professor | a professora |
| o leão | a leoa |
| o pai | a mãe |

> [!TIP]
> Muitos nomes femininos terminam em **-a**. Mas há exceções, por isso presta atenção!

---

## Singular e Plural

O **singular** fala de uma coisa. O **plural** fala de mais de uma coisa.

| Singular | Plural | Regra |
|----------|--------|-------|
| livro | livros | acrescenta **-s** |
| flor | flores | acrescenta **-es** |
| pão | pães | muda o final |
| lápis | lápis | não muda |

> [!IMPORTANT]
> Para formar o plural, a regra mais comum é acrescentar **-s** ao singular.

2. **Escreve no feminino**: o lobo → a \_\_\_\_ / o rei → a \_\_\_\_ / o aluno → a \_\_\_\_.
3. **Escreve no plural**: a bola → as \_\_\_\_ / o lápis → os \_\_\_\_ / a flor → as \_\_\_\_.
4. **Reescreve a frase** corretamente: *o cão ladra para a lua* (não te esqueças da maiúscula e do ponto!)
