# Data Handling — Year 4

Data is all around us! Every time we count things, survey our friends, or record results, we're **handling data**. Learning to collect, organise, and read data is one of the most useful skills in real life! 🌍

---

## What is Data?

**Data** is information — especially information that can be counted or measured.

Examples of data we might collect:
- 🌤️ How many sunny days each month?
- 🎨 What is everyone's favourite colour?
- 📚 How many books did each student read?
- 🍎 What fruit did students bring for lunch?

> [!NOTE]
> Data that comes in categories (like colours or fruits) is called **categorical data**. Data that involves numbers (like heights or scores) is called **numerical data**! 📊

---

## Step 1 — Collecting Data

Before we can analyse data, we need to **collect** it! Common ways:

| Method | How it works | Best for |
|--------|-------------|----------|
| **Survey / Questionnaire** | Ask people questions 🗣️ | Opinions, preferences |
| **Observation** | Watch and count 👀 | Traffic, behaviour |
| **Experiment** | Test and record 🔬 | Science results |
| **Existing records** | Use data already collected 📂 | Weather, population |

> [!TIP]
> Always decide **what question you want to answer** before collecting data. This keeps your data collection focused! 🎯

---

## Step 2 — Frequency Tables

A **frequency table** organises data into a tidy list showing **how many times** each item appears. The count is called the **frequency**.

### Example: Favourite Pets Survey (Class of 24 students)

| Pet | Tally | Frequency |
|-----|-------|-----------|
| Dog 🐕 | \\|\\|\\|\\| \\|\\|\\|\\| \\| | 11 |
| Cat 🐱 | \\|\\|\\|\\| \\|\\| | 7 |
| Fish 🐟 | \\|\\| | 2 |
| Rabbit 🐰 | \\|\\|\\| | 3 |
| Bird 🐦 | \\| | 1 |
| **Total** | | **24** |

$$\text{Total frequency} = 11 + 7 + 2 + 3 + 1 = 24 ✅$$

> [!IMPORTANT]
> Always check that your frequencies **add up to the total number of people/items** you surveyed! It's an easy way to spot mistakes. ✅

---

## Step 3 — Bar Charts

A **bar chart** (or bar graph) shows data using **rectangular bars**. The taller the bar, the higher the value.

```chart
type: bar
title: Favourite Pets — Year 4
labels: [Dog, Cat, Fish, Rabbit, Bird]
data: [11, 7, 2, 3, 1]
colors: [#388bfd, #3fb950, #22d3ee, #a371f7, #f87171]
```

### How to Draw a Bar Chart

1. Draw **horizontal axis (x-axis)** → write category labels
2. Draw **vertical axis (y-axis)** → write a numbered scale
3. Draw **bars** for each category — all the same width, all gaps equal
4. Give your chart a **title** and label both axes

> [!TIP]
> Always choose a **scale** that lets all your data fit on the chart. If your biggest value is 24, a scale going up by 2s or 4s works well! 📏

---

## Step 4 — Pictograms

A **pictogram** uses **pictures or symbols** to represent data. Each symbol represents a certain number of items.

### Example: Books Read in a Month

| Student | Books | Pictogram |
|---------|-------|-----------|
| Alfie | 6 | 📚📚📚 |
| Bella | 4 | 📚📚 |
| Carlos | 8 | 📚📚📚📚 |
| Diana | 2 | 📚 |

**Key:** 📚 = 2 books

$$\text{Carlos read: } 4 \text{ symbols} \times 2 = 8 \text{ books}$$

> [!NOTE]
> Always include a **key** in your pictogram so readers know what each symbol represents! A half-symbol means half the key value. 🔑

---

## Line Charts

A **line chart** shows how data **changes over time**:

```chart
type: line
title: Temperature during the week (°C)
labels: [Mon, Tue, Wed, Thu, Fri, Sat, Sun]
data: [18, 20, 22, 19, 23, 25, 24]
```

> [!TIP]
> Line charts are great for showing **trends** — the line goes up when the value increases and down when it decreases!

---

## The Mode

The **mode** is the value that appears **most often** in a set of data. It's the most popular item!

### Finding the Mode

Data: 🔴🔵🔴🟢🔴🔵🔴🟡

Count: 🔴 appears **4 times**, 🔵 appears 2 times, 🟢 appears 1 time, 🟡 appears 1 time.

$$\text{Mode} = 🔴 \text{ (most frequent)}$$

**Favourite pet example:** Dog appeared 11 times — the **mode is Dog** 🐕

> [!TIP]
> The **mode** is the only average that works for words/categories, not just numbers! You can find the mode of favourite colours, sports, or foods! 🎨

## Interpreting Graphs

Reading a graph means **answering questions** about the data it shows. Always:

1. **Read the title** — what is the graph about?
2. **Check the scale** — what does each unit represent?
3. **Compare the bars/symbols** — which is biggest? Smallest?
4. **Draw conclusions** — what does the data tell you?

### Questions to Ask About Data

| Type of question | Example |
|-----------------|---------|
| Reading a value | "How many students chose cats?" |
| Comparing | "Which pet is most popular?" |
| Calculating difference | "How many more chose dogs than fish?" |
| Finding the mode | "What was the most common answer?" |
| Finding total | "How many students were surveyed?" |
