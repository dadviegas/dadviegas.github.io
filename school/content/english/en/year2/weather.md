# Weather

## Introduction

Talking about the weather is one of the most common topics in English conversation! Whether you're making small talk or listening to a forecast, these words will be very useful.

## Nouns vs Adjectives

| Noun | Adjective |
|------|-----------|
| sun | sunny |
| cloud | cloudy |
| rain | rainy |
| wind | windy |
| snow | snowy |
| fog | foggy |
| storm | stormy |

> [!TIP]
> To describe weather as a noun, say **"There is + noun"**: *There is fog today.*
> To use an adjective, say **"It is + adjective"**: *It is foggy today.*

## Talking About the Weather

| Question | Portuguese |
|----------|-----------|
| **What's the weather like?** | Como está o tempo? |
| **What's the weather like today?** | Como está o tempo hoje? |
| **How's the weather?** | Como está o tempo? |

| Answer | Portuguese |
|--------|-----------|
| **It's sunny.** | Está sol. |
| **It's raining.** | Está a chover. |
| **It's snowing.** | Está a nevar. |
| **It's cold.** | Está frio. |
| **It's hot.** | Está calor. |
| **It's warm.** | Está quente / ameno. |
| **It's freezing!** | Está a congelar! |
| **It's boiling!** | Está um calor enorme! |

## Dressing for the Weather

| Weather | What to wear |
|---------|-------------|
| rainy | a raincoat / an umbrella |
| cold | a coat, a scarf, gloves |
| sunny | a t-shirt, sunscreen, sunglasses |
| snowy | a warm coat, boots, hat |

> [!TIP]
> The classic British conversation opener: **"Lovely weather, isn't it?"** — Even if it's raining!
